# 🤪 Хохмач

Пати-игра для компании в духе Jackbox / Quiplash. Главный экран — на компьютере или телевизоре, игроки отвечают с телефонов. Никакого сервера: чистый статический сайт, который хостится на GitHub Pages.

## Как играть

1. Откройте `host.html` на большом экране — появится код комнаты и QR-код.
2. Игроки (3–8 человек) открывают сайт на телефоне, вводят код и имя (или сканируют QR).
3. Первый вошедший — **VIP**, он может запустить игру с телефона (или нажмите «Начать игру» на главном экране).
4. **Раунды 1 и 2:** каждый вопрос получают два игрока. Остальные голосуют, чей ответ смешнее.
   Голос = 100 очков (×2 во втором раунде), победа в битве — бонус, все голоса за один ответ — **РАЗНОС!**
5. **Финал:** один вопрос для всех, каждый голосует за лучший чужой ответ (голос = 300 очков).

## Как это работает

- Игроки соединяются с главным экраном напрямую через WebRTC ([PeerJS](https://peerjs.com/)).
  Для «знакомства» браузеров используется бесплатный публичный сервер PeerJS, через него не идут данные игры.
- Главный экран хранит всё состояние игры и рассылает каждому телефону, что показывать.
- Телефоны автоматически переподключаются, если заснули или перезагрузили страницу.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте в него эти файлы.
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.
   - главный экран: `…/host.html`
   - игроки: `…/` (корень сайта)

## Локальный запуск

```bash
python -m http.server 8765
```

Откройте `http://localhost:8765/host.html`. Чтобы потестировать на одном компьютере несколькими игроками,
откройте вкладки `http://localhost:8765/?t=1`, `?t=2`, `?t=3` — у каждой будет свой игрок.

## Свои вопросы

Добавьте строки в `js/prompts.js` (массив `PROMPTS`).
